# Color-Bar-with-VGA-on-Basys3

Features
• VGA 640×480 @60Hz output
• 25 MHz pixel clock generation
• Horizontal and vertical synchronization
• RGB color bar rendering
• Modular VHDL architecture


VGA Color Bar project developed on Basys3 FPGA using VHDL. This project serves as a foundation for future video processing, animation, and image processing applications.
